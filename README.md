# MonkeytypeWebsite

A simple and interactive typing speed test website inspired by platforms like Monkeytype.
Built using HTML, CSS, and JavaScript.

Features :-
- Multiple timer options (15s / 30s / 60s)
- Real-time WPM calculation
- CPM (Characters Per Minute) tracking
- Accuracy calculation
- Fun typing personas:
  Tortoise
  Horse
  Cheetah
- Restart functionality
- Clean dark-themed UI

How It Works 
1.Select a test duration.
2.Start typing the displayed paragraph.
3.The timer begins automatically on the first key press.
4.Your:
WPM
CPM
Accuracy
Typing Persona
are calculated in real time.
5.Click Restart to try again.
